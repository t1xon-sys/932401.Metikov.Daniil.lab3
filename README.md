# Лабораторная работа №3. Вёрстка макета с помощью Flexbox и Grid


**Тема:** «Студент-разработчик» (витрина проектов и скриншоты)

## Цель

Освоить Flexbox для одномерных макетов, CSS Grid для двумерных и принципы адаптивной вёрстки.


## Что сделано


### Flexbox
- **Навигационное меню** (`.nav-list`): на мобильных пункты идут столбцом, на экранах от 600px — в горизонтальный ряд с переносом (`flex-wrap`).
- **Карточки проектов** (`.project-card`, 5 шт.): каждая карточка — `<article>`; внутри иконка слева и текст справа (`display: flex`).
- Контейнер карточек (`.projects-list`) — `display: flex` с `flex-wrap`.

### Grid
- **Галерея «Скриншоты проектов»** (`.gallery`): 4 ячейки, каждая — `<figure>` с `<img>` и `<figcaption>`.
- Блок навыков (`.skills-grid`) тоже построен на Grid (`auto-fit`, `minmax`).


### Адаптивность
| Экран | Карточки проектов | Галерея |
|-------|-------------------|---------|
| Мобильный (до 600px) | 1 колонка | 1 колонка |
| Планшет (от 600px) | 2 колонки | 2 колонки |
| Десктоп (от 992px) | 3 колонки | 3 колонки |

Горизонтальная прокрутка отсутствует: `box-sizing: border-box`, `img { max-width: 100% }`, `overflow-x: hidden`, `overflow-wrap: anywhere` в карточках.


### Контрастность
- Текст в карточках проектов — белый на тёмном полупрозрачном оверлее (`rgba(0, 0, 0, 0.7)`, псевдоэлемент `::before`), контрастность ≥ 4.5:1.
- Фон-картинка карточки задаётся через CSS-переменную `--card-img`.
